# Third-party dependencies and assets

The MIT license applies to project-owned source only. No third-party source or
library binary is re-licensed by this repository. Native dependencies are resolved
externally through the package's link settings and must retain upstream notices.

| Component | Use | Upstream licensing reference |
|---|---|---|
| OpenCV 4 | SIFT/FLANN, homography, warping, blending | Apache-2.0 for modern OpenCV; https://opencv.org/license/ |
| Ceres Solver | Camera optimization | BSD-3-Clause; https://github.com/ceres-solver/ceres-solver/blob/master/LICENSE |
| Eigen | Linear algebra headers | MPL-2.0, with Apache-2.0, BSD-3-Clause and Minpack notices for specific components; https://libeigen.gitlab.io/docs/TopicLicense.html |
| LibRaw | RAW decoding | LGPL-2.1 / CDDL-1.0 alternatives; inspect the selected build and optional components at https://www.libraw.org/download |
| libtiff | TIFF I/O | libtiff license and retained component notices; https://libtiff.gitlab.io/libtiff/misc.html |
| glog | Ceres logging dependency | BSD-3-Clause; https://github.com/google/glog/blob/master/COPYING |
| Apple frameworks | SwiftUI/AppKit, CoreGraphics/ImageIO, Metal | Supplied by Apple SDK/macOS, not redistributed here |

The development baseline inspected in September 2026 used OpenCV 4.13.0,
Ceres 2.2.0, Eigen 5.0.1, LibRaw 0.22.1, libtiff 4.7.2, and glog 0.7.1.
This is a dependency inventory, not a complete binary-distribution SBOM. Any future
application bundle must audit its exact transitive dylib closure, retain all
applicable license texts, and satisfy the selected LibRaw distribution terms.

`Resources/AppIconSource.png` is project-directed AI-generated artwork. It may be
used to build and identify PanoLume; it is not included in the source-code MIT grant.
No camera photographs, external project files, camera profiles, or third-party
rendered panoramas are included. Synthetic test inputs are generated by the tests.
